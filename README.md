# Ethan Helps — Geometry Study Platform

Clean study platform for Geometry with accounts, subscription tiers, quizzes, notes, and unit grades.

## Phase 1 features
- Secure login (bcrypt + JWT cookies)
- Roles: Owner, Staff, Student
- Tiers: Ethan’s Basic / Premium / Platinum
- Admin panel to create users and assign tiers
- Chapters 7 & 8 (units, notes, practice quizzes)
- Unit Grade & Mastery system
- Support contact form
- Dark, modern UI
